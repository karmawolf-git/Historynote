# HistoryNote — HCP 관심사·성향 태깅 미니 CRM

의사(HCP)별 관심 주제와 성향을 구조화해서 기록·분석하는 제약영업(MR)용 미니 CRM입니다.
서버·설치 없이 브라우저에서 `index.html`을 열면 바로 동작합니다.

## 주요 기능

- **병원 → 진료과 → 교수 트리** — 사이드바에서 병원별/과별로 의사 리스트를 접고 펼치며 탐색
- **관심 키워드 자동 태깅** — 대화 후 메모를 저장하면 `당뇨`, `약가`, `급여 기준`, `부작용`, `임상 근거` 등
  20여 개 표준 태그가 자동 추출됨 (메모별 누적 횟수 표시, 수동 태그 추가도 가능)
- **성향 분석** — 메모에서 `근거 중시`, `약가 민감`, `안전성 중시` 같은 성향을 추출하고
  *"이 의사는 약가보다 근거 수준에 민감함"* 식의 요약 + 다음 방문 시 접근 전략 제공
- **관심사 기반 자료 추천** — 누적 태그와 자료 카탈로그를 매칭해 디테일 자료 추천
- **태그 버튼 팔레트** — 표준 태그를 버튼 클릭으로 추가/해제 (자동 추출된 태그는 점선으로 표시)
- **Hospital TimeTable 연동** — [HTimeTable](https://karmawolf-git.github.io/HTimeTable/)에서
  스케줄 사진을 분석해 복사(⎘)한 표를 `📅 스케줄 가져오기`에 붙여넣으면
  의사 명단과 외래 일정이 병원 단위로 일괄 등록/업데이트됨
- **검색** — 이름·병원·과·외래 일정·태그·성향으로 즉시 필터
- **백업** — JSON 내보내기/가져오기

## AI 연동 (선택)

기본적으로 **내장 한국어 키워드 사전**으로 오프라인 자동 태깅이 동작합니다.

⚙️ 설정에서 Anthropic API 키를 입력하면:

- 메모 저장 시 **Claude(claude-opus-4-8)** 가 문맥을 이해해 태그·성향을 추출 (structured output 사용,
  실패 시 사전 기반으로 자동 폴백)
- 전체 메모 이력을 바탕으로 한 **AI 성향 요약** 생성 가능

API 키는 브라우저 localStorage에만 저장되며, Anthropic API 외 어디로도 전송되지 않습니다.

## 시작하기

1. `index.html`을 브라우저로 엽니다 (또는 `python3 -m http.server` 등 정적 서버 사용)
2. 첫 화면에서 **샘플 데이터 불러오기**를 눌러 동작을 확인하거나, **+ 의사 추가**로 시작
3. 의사를 선택하고 대화 메모를 입력 → 자동 태깅·성향 요약·자료 추천 확인

## 구조

```
index.html          앱 진입점 (모달 포함)
css/styles.css      스타일
js/dictionary.js    태그/성향 키워드 사전, 접근 전략, 자료 카탈로그
js/store.js         localStorage 데이터 계층
js/tagger.js        규칙 기반 + Claude AI 태깅/요약 엔진
js/sample-data.js   데모용 샘플 데이터
js/app.js           UI 렌더링·이벤트
```

## 데이터 모델

```json
{
  "hcps": [{
    "id": "…", "name": "김민준", "hospital": "서울중앙병원",
    "department": "내분비내과", "title": "교수",
    "manualTags": ["당뇨"],
    "notes": [{
      "date": "2026-06-11T…", "text": "약가가 부담된다고 함…",
      "tags": ["약가", "신약"], "traits": ["약가 민감"]
    }],
    "aiSummary": "…"
  }]
}
```

태그·성향 사전은 `js/dictionary.js`에서 자유롭게 추가/수정할 수 있습니다.
